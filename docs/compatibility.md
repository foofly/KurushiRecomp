# Compatibility status

The USA release (SCUS-94181) boots to the main menu and enters a playable puzzle. Menu selection, puzzle movement, marking, scoring capture, Advantage Zone activation, pause/resume, and Start Over were exercised in local runs.

The user also reported successful play with a PS5 controller. This confirms a practical local play session, but not a complete-game clear or exhaustive compatibility.

Still unqualified: full puzzle completion, all collision and penalty cases, progression and save persistence, timing/audio parity against original hardware, full OpenGL gameplay, and coverage of all translated code paths. Interpreter fallback remains available, so this project does not claim complete static recompilation.

The source repository excludes the disc, extracted executable, generated game code, BIOS dumps, saves, and gameplay captures. Reproduce locally with the matching USA disc as described in the top-level README.
